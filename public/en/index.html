Method

How one person delivers the scope of a team.

Built with Claude Code

I build with Claude Code, Anthropic's coding agent, always on the most capable models on the market at the time of the project. That is what lets one person cover mock-ups, code, database, deployment, copy and SEO.

Online from day one

Each batch goes live the same day. You review on your phone, I fix within the day. On Institut Molière: 524 releases in 20 days.

Measured, never eyeballed

Colour contrast, tap targets, overflow on phones, links, console errors: checked by script and in the browser before every release.

Working first, pretty second

A site must render in full inside the Instagram or Facebook in-app browser, where visitors come from. No content depends on an animation; at the slightest doubt, the ornament goes.

Documented to be taken over

Every project ships with a hand-over document: where everything lives, how to change a setting, what remains to do. Nothing depends on my memory.

Nothing promised that doesn't exist

Every number on this site has a source and a date. The script that recounts them lives in the site's public repository, and it blocks the release if a number has drifted.
