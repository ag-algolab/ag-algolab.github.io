Un site qu'on lit sur un téléphone, et qui fait écrire.

C'est sur un écran de six pouces qu'on décide de vous appeler ou pas. Le site est dessiné pour ce moment-là : une promesse lisible, vos prix, et un bouton qui écrit à votre place.

Demander un prix Ce qui fait varier le prix

Ce que vous recevez

Tout compris, rien à rajouter après.

  • Une direction artistique dessinée pour votre métier, jamais un gabarit recolorié.
  • Vos textes, travaillés avec vous : ce que vous faites, pour qui, à quel prix.
  • Un formulaire, ou un bouton WhatsApp qui pré-remplit le message.
  • Le référencement, l'image de partage, les mentions légales.
  • Le nom de domaine, l'hébergement, la mise en ligne.
  • Vos prix et vos offres modifiables sans moi.

La différence

Le même soin que sur mes propres produits.

Un script refuse la mise en ligne si quelque chose cloche : contraste du texte, boutons trop petits pour un doigt, lien mort, image agrandie donc floue. Netteté minimale mesurée sur ce site : 2,0 pixels d'image par pixel affiché.
