Method

I don't execute a spec. I bring the vision, then I build it.

Five steps, always in this order. Scroll: the path draws itself.

    The vision

    You describe your activity in three lines. I don't come back with a quote: I come back with the product you hadn't drawn — the free test that fills registrations, the report families get on its own, the alert when a pupil drops off.

  4. 04

    Measured, never eyeballed

    A script blocks the release if something is off: contrast, buttons too small, broken links, an upscaled image gone blurry. The figures are recounted before every publication — if a number moves, the text follows, or nothing ships.

    verifier.py · before every release

    • ✓tap targets≥ 44 px
    • ✓overflow at 390 px0 px
    • ✓links and images0 broken
    • ✓image pixels per displayed pixel≥ 2.0
